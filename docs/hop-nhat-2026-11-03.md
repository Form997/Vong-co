# Bản hợp nhất kỹ thuật HAI ĐẤT Vọng cổ

Ngày bắt đầu: **03/11/2026**. Thế hệ học liệu vẫn là **V3.6**; đây là đợt hợp nhất và gia cố mã, không tự nâng mức nghiệm thu âm nhạc.

## Một nhánh phát hành

`main` chứa website, bộ kiểm dữ liệu V2–V3.6, MCP chỉ đọc và bộ quét metadata. Các thay đổi #29 và #30 đã được hợp nhất vào nhánh đích trước khi gom mã. Bản hợp nhất giữ toàn bộ tệp riêng của main và dùng hồ sơ V2 đã được bộ kiểm website đối chiếu từ V3.6. Không xóa nhánh cũ; `v1-frozen` giữ nguyên tại `f6537c83878bca079752dbdd4baec5b1164a1ab4`.

## Chạy tại máy

Yêu cầu Python 3.11 trở lên; Node.js 22 cho kiểm thử JavaScript. Website tĩnh không cần khóa API hoặc GPU.

```bash
python -m unittest discover -s tests -v
node --test tests/auto_update.test.cjs
python scripts/v3_build_site.py --out _site
python -m http.server 8765 --directory _site --bind 127.0.0.1
```

Mở `http://127.0.0.1:8765/`. Thư mục `_site` phải rỗng hoặc chưa tồn tại trước khi dựng; không dùng thư mục chứa dữ liệu cá nhân làm đầu ra.

MCP: xem [hướng dẫn cài đặt](../integrations/vong-co-mcp/README.md). Quét metadata: xem [hướng dẫn V3.6](v3.6-tu-dong-nguon-va-bao-ve-nhanh.md). `OPENALEX_API_KEY` là tùy chọn, không cần để mở website.

## Xuất bản

- GitHub Pages: workflow `pages-v3.yml` kiểm Python, dữ liệu, JavaScript và Chromium trước khi tải artifact; chỉ triển khai commit mới nhất trên `main`. PR chỉ dựng và kiểm, không triển khai production.
- Netlify: cấu hình trong `netlify.toml`, build bằng Python, xuất `_site`. Site phải liên kết đúng kho và chọn production branch `main`. Tệp cấu hình không tự thay đổi lựa chọn nhánh trong tài khoản Netlify.
- Liên kết hồ sơ, nguồn và chính sách trong giao diện trỏ về bản hợp nhất trên `main`.

Trước PR: 131 kiểm thử Python cấp kho, 15 kiểm thử catalog/MCP ngoại tuyến và 6 kiểm thử JavaScript đạt. GitHub Actions tiếp tục kiểm giao thức MCP và Chromium trên commit hợp nhất. Số liệu dung lượng cuối được ghi trong `docs/hop-nhat-build.json`.
